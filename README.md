# CatalogodeEsp-cies
Catálogo de características de espécies de peixes
Nomes : Douglas Henrique da Silva Caetano, Yasmin Bezerra da Silva e Guilherme Vitor Gomes. 
Data de Entrega: 19/11/2026

Descrição do projeto: 
Catálogo Interativo de Espécies de Peixes. Permite listar espécies de água doce e marinhas, cadastrar novos peixes, pesquisar no banco de dados e editar registros. O sistema utiliza uma interface web desenvolvida em Python.

Instruções de execução:
1. Instale a biblioteca necessária: pip install streamlit
2. Rode o comando: streamlit run app.py
3. O site abrirá no navegador.

Bibliotecas utilizadas: streamlit, json, os

- Gilherme : Desenvolvimento e pesquisa de espécies
- Yasmin : Desenvolvimento e pesquisa de espécies
